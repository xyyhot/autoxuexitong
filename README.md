# 学习通连续播放助手

当前版本：**1.0.1**。修复了切换后首次播放请求失败就停止的问题，增加原生播放按钮初始化、加载事件监听和最长 30 秒的启动重试。重试期间仍会响应暂停和页面答题/验证提示。

## 安装和使用

1. 在电脑 Edge 的油猴（Tampermonkey）管理面板中新建脚本。
2. 打开同目录的 `chaoxing-autoplay.user.js`，复制全部内容，替换新建脚本中的默认内容并保存。
3. 进入学习通的具体课程 → 章节 → 视频页，然后刷新页面。个人空间首页不会显示助手。
4. 点击右下角“开始”，从当前章节往后处理。点击“暂停”会停止播放；处理页面提示后再点击“开始”可恢复。

更新旧版时，直接用本次文件的全部内容覆盖油猴中的原脚本并保存，再刷新课程页。面板标题显示 `v1.0.1` 才说明新版已经生效；不要同时启用两份助手脚本。

支持已检查的 `*.chaoxing.com/mycourse/studentstudy` 网页模板，也匹配带 `/mooc-ans` 前缀的同类路径。若没有面板，先检查当前网址、油猴是否启用、该脚本是否启用，以及扩展是否有当前站点的运行权限。

## 默认行为

- 静音播放；先尝试播放器原生静音控件，未生效时使用 HTML 视频静音属性。
- 课程允许且原生菜单有二倍速选项时设置二倍速；禁止倍速、菜单不可用或设置失败时继续原速播放。
- 从当前章节向后，跳过目录已完成的章节及视频任务；同节多个视频依次播放，同节有多个内容页时依次检查，纯非视频页会跳过。
- 视频任务点由网站确认完成后才切换。没有任务点标记的视频按自然播放结束处理。不会根据“播放到 90%”自行判定完成。
- 视频结束后最多等待网站确认 30 秒；加载超过 30 秒或播放超过 60 秒未前进时暂停提示。
- 遇到视频弹题、验证、登录提示、媒体错误或手动暂停时停止。处理完成后点击“开始”。独立的非视频练习页会跳过，不会自动答题。
- 同一标签页、同一课程刷新后恢复运行状态；手动暂停后刷新不会恢复。课程切换后需要重新开始。跳过计数只统计本次页面会话，不是网站完成总数。

脚本使用现有登录状态和原生播放流程，无外部依赖；不会修改网站完成标记或发送自制学习进度请求。运行记录仅包含课程/班级标识、章节标识和运行状态，保存在当前站点的 `sessionStorage` 中。

脚本语法检查通过，36 项模拟场景测试全部通过，详见 `验证说明.md`。

2026-11-03 已在“程序设计基础”的实际网页检查目录、完成标记、内容分页、嵌套播放器与倍速限制，并通过原生控件验证原速播放及相邻章节切换。当前样例明确提示“未完成任务点前，当前视频不可倍速、不可拖拽”，脚本按原速处理。

用户已现场确认旧版能够完成后切换到下一视频，但下一视频未自动启动；实际页面显示旧版在首次启动失败后停止。v1.0.1 已针对启动流程补充修复和回归测试，尚未覆盖浏览器中的旧版，需要更新后再次确认真实课程的连续播放。其他学校的定制页面、跨域播放器或不同任务模板不保证兼容；识别失败时会暂停并提示。
